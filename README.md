# Coach Ziah Volleyball

A responsive, single-page coaching website for private volleyball training, small-group sessions, team clinics, and remote video analysis in the Milwaukee area.

## Included

- Bold responsive landing page
- Coaching value proposition
- Private, group, team, and video-review services
- Market-informed pricing cards
- Mobile navigation
- Scroll reveal motion with reduced-motion support
- Contact form that creates a prefilled email request

## Run locally

No build tools are required.

```bash
python -m http.server 8080
```

Open `http://localhost:8080`.

## Before launch

Replace the placeholder email address `coachziahvolleyball@gmail.com` in `index.html` and `script.js` if a different business email should be used.

For direct online booking, replace the contact form or primary booking links with a Calendly, Square Appointments, Acuity, or Google Calendar booking URL.

## Hosting

The site can be deployed directly with GitHub Pages, Netlify, Cloudflare Pages, or Vercel because it is fully static.
